# E4A - Ebay for Africa

A simple marketplace website for buying and selling used items in Africa.

## Features

- Buyer and seller registration and login
- Product listing with images, categories, and prices
- Add new products for sale
- Contact page for messaging the site owner
- Admin dashboard for managing products, contacts, and users

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the server:

```bash
npm start
```

3. Open the browser at `http://localhost:3000`
