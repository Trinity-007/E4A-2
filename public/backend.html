This page gives you direct access to backend data and raw API results after admin login.

API Endpoints

  • /api/products - list products
  • /api/products?category=CategoryName - filter products
  • /api/contact - submit contact form
  • /api/messages - your inbox/messages
  • /api/admin/contacts - admin contact messages
  • /api/admin/products - admin product list
  • /api/admin/users - admin user list
  • /api/admin/messages - admin direct messages
